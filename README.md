# Hunter Father

Браузерная 3D-охота от первого лица (Three.js + Vite). ПК и iPhone (Safari).

## Запуск локально

Нужны два процесса — клиент (Vite) и сервер (Wrangler, локальная копия Cloudflare):

```bash
npm install
npm --prefix server install
npm run server      # сервер на :8787 (в отдельном терминале)
npm run dev         # клиент на :5173
```

Без сервера работает «Одиночная охота»; «Создать комнату» и «Войти» требуют сервер.
Приглашение по ссылке: `http://…/?room=КОД`.

Откройте http://localhost:5173. Сервер слушает и в локальной сети: с iPhone в той же Wi‑Fi
откройте `http://<IP-вашего-Mac>:5173` (адрес Vite выводит в строке `Network:`).

Отладка: `?touch` в адресе — включить сенсорный интерфейс на ПК; клавиша **H** — показать хитбоксы.

## Управление

- **ПК:** WASD — ходьба, Shift — бег, мышь — обзор, ЛКМ — выстрел, ПКМ — оптика, R — перезарядка, Space — прыжок, F — сесть в машину / подняться на вышку, Esc — пауза.
- **В машине:** W/S — газ/тормоз и задний ход, A/D — руль, Space — ручник, V — вид из кабины, мышь — осмотреться, F — выйти.
- **iPhone:** левый джойстик — ходьба (до упора — бег) или газ/руль в машине, свайп справа — обзор, кнопки выстрела/оптики/перезарядки/прыжка; 🚙 — сесть/выйти/вышка, 👁 — вид в машине.

## Мир

- Карта 800×800 м: холмы, лес, поляны, река, горы по краям; грунтовые дороги от базы к 6 избушкам.
- База охотников у старта: изба, сарай, поленницы, кострище, **два внедорожника** (Range Rover и пикап).
- 6 охотничьих вышек на опушках.
- Животные (~55): стада оленей, благородные олени, кабаны (раненый кабан атакует), зайцы, лисы, волчьи стаи (нападают на пешего охотника, в машине и на вышке вы в безопасности). Популяция восполняется вдали от игрока.

## Онлайн

- Комнаты до 8 охотников, вход по 5-символьному коду.
- Сервер авторитетный: животные, попадания (с компенсацией задержки), очки — считаются в Durable Object.
- Видно других охотников с никами, их выстрелы (звук по расстоянию), машины, которыми они управляют.
- Таблица очков — Tab (или 🏆): охотники в комнате + рекорды комнаты (SQLite). Общий топ — в меню.
- При обрыве связи клиент сам переподключается к той же комнате.
- Деплой — см. [DEPLOY.md](DEPLOY.md).

## Структура

```
server/          Cloudflare Worker + Durable Objects (Room, Leaderboard)
shared/          общий код клиента и сервера (без three.js)
  protocol.js    сетевые константы
  terrain.js     высоты, река, биомы — детерминированно
  world.js       деревья/камни, коллизии, проверка линии огня
  animals.js     ИИ и хитбоксы животных (авторитетная симуляция)
src/
  config/models.js   реестр .glb-моделей — меняйте модели здесь
  config/settings.js пресеты графики (низкая/средняя/высокая)
  world/             рельеф (splat-шейдер PBR), трава, деревья (карточки + импостеры), избы, вода, небо
  vehicles/          физика и камера машин
  player/            игрок и винтовка
  entities/          загрузка моделей, животные, другие охотники
  net/               WebSocket-клиент
public/textures      CC0 PBR-текстуры (см. CREDITS.md)
public/models        CC0 модели Quaternius
tools/compress-textures.sh  JPG → KTX2 (Basis) для экономии видеопамяти
```

## Замена моделей

Положите `.glb` в `public/models/` и поправьте запись в `src/config/models.js`:
`url`, `height` (высота в метрах — модель масштабируется автоматически), `yaw`
(если модель смотрит не в +Z) и имена анимаций (`idle/walk/run/eat/death/attack`).
Хитбоксы для попаданий задаются в `shared/animals.js` → `SPECIES`.

## Производительность

- Трава — 1 draw call (инстансы вокруг игрока, высота из текстуры, ветер в шейдере).
- Деревья — InstancedMesh с двумя уровнями LOD, тени только у ближних.
- Материалы Quaternius склеиваются в один (цвета вершин) → 1 draw call на животное.
- Сцена целиком ≈ 20–30 draw calls.
- Сжатые текстуры: `tools/compress-textures.sh` (нужен `ktx` из KTX-Software), игра подхватит их автоматически.
